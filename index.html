Hermes Sheets

Hermes Sheets is a private desktop integration used by its account owner to work with Google Drive and Google Sheets.

Purpose

The application reads and edits spreadsheets and Drive files only when the account owner asks it to perform a task. It is not offered as a public service.

Data handling

OAuth credentials are stored locally on the owner's Windows device. The application does not sell Google user data or use it for advertising.
